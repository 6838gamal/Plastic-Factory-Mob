# Seed Data Initialization

قم بإنشاء نظام Seed Data ذكي.

المطلوب:

* فحص البيانات الحالية أولاً.
* عدم إنشاء سجلات مكررة.
* عدم حذف البيانات الموجودة.
* إضافة البيانات المفقودة فقط.

استخدم Upsert وليس Insert فقط.

# القيم الافتراضية

لكل مادة خام:

الوحدة = كيلوجرام

الحالة = نشط

حد إعادة الطلب = 0

الرصيد الافتتاحي = NULL

الرصيد الحالي = NULL

---

# قواعد مهمة

لا تضع أي أرصدة افتتاحية.

لا تضع أي كميات مخزون.

لا تضع أي أسعار شراء.

لا تضع أي استهلاك.

لا تضع أي بيانات تشغيلية.

أنشئ الهيكل فقط.

سيتم إدخال:

* الرصيد الافتتاحي
* الأسعار
* حدود إعادة الطلب

لاحقاً من لوحة الإدارة.

---

# التحقق بعد التنفيذ

أعطني تقريراً يوضح:

* عدد السجلات التي أضيفت.
* عدد السجلات التي كانت موجودة مسبقاً.
* السجلات التي تم تحديثها.
* السجلات التي تم تجاهلها بسبب التكرار.

ويجب أن تكون عملية Seed قابلة للتشغيل عدة مرات دون إنشاء بيانات مكررة.
