# إعادة بناء واستكمال قاعدة بيانات نظام مصنع البلاستيك

قم بتحليل النظام الحالي أولاً ثم استكمل بناء قاعدة البيانات بطريقة آمنة دون حذف أو كسر أي جدول أو بيانات أو أتمتة موجودة.

اعمل بأسلوب:

Schema Migration + Data Migration + Integrity Validation

وليس Delete & Rebuild.

---

* هل موجود؟
* هل مكتمل؟
* هل توجد حقول مفقودة؟
* هل توجد علاقات مكسورة؟
* هل توجد حقول مكررة؟
* هل توجد معادلات ناقصة؟

أصلح الموجود قبل إنشاء أي شيء جديد.

# التحقق من الخصميات (مهم جداً)

افحص جميع عمليات الخصم الحالية.

تأكد أن:

عند حفظ طبخة:

1. يتم إنشاء Transaction ID.
2. يتم إنشاء حركة مخزون.
3. يتم خصم جميع المواد المستخدمة.
4. يتم تحديث الرصيد الحالي.
5. يتم تحديث أرصدة المخزون.
6. يتم تسجيل Audit Log.
7. يتم إنشاء Alert إذا أصبح المخزون منخفضاً.

---

## منع الخصم المكرر

إذا تم تنفيذ العملية مسبقاً بنفس Transaction ID:

يمنع إنشاء خصم جديد.

---

## منع الرصيد السالب

إذا كانت الكمية المطلوبة أكبر من الرصيد:

* منع الحفظ.
* إنشاء تحذير.
* تسجيل الحدث.

---

## تعديل الطبخات

عند تعديل الطبخة:

* عكس الخصميات القديمة.
* تطبيق الخصميات الجديدة.
* إعادة احتساب الرصيد.

---

# التقرير النهائي

بعد التنفيذ أعطني:

* الجداول التي تم إنشاؤها.
* الجداول التي تم تحديثها.
* الحقول التي تمت إضافتها.
* العلاقات التي تم إصلاحها.
* المعادلات التي تم إنشاؤها.
* حالة نظام الخصميات.
* نتيجة اختبار الخصم.
* نتيجة اختبار الرصيد السالب.
* نسبة اكتمال النظام.

ولا تقم بحذف أو كسر أي جزء موجود مسبقاً أثناء التنفيذ.
