# قواعد مهمة جداً

━━━━━━━━━━━━━━━━━━━━━━

1. لا تقم بتغيير رابط الـ API الحالي.

يجب أن يبقى:

https://plastic-factory-api.onrender.com

هو الرابط الرسمي للإنتاج.

2. لا تقم باستبدال قاعدة البيانات الحالية.

3. لا تقم بإنشاء قاعدة بيانات جديدة.

4. لا تقم بحذف أي بيانات.

5. لا تقم بإعادة تهيئة قاعدة البيانات.

6. لا تقم بتنفيذ:

* DROP TABLE
* DROP SCHEMA
* TRUNCATE
* RESET DATABASE

7. يجب الحفاظ على التوافق الكامل مع البيئة الحالية.

8. أي تحديث يجب أن يكون Backward Compatible.

جعل المشروع مستقراً وقابلاً للنشر والعمل خارج Replit بنسبة 100% مع الحفاظ الكامل على قاعدة البيانات الحالية ورابط API الحالي وعدم التأثير على بيانات الإنتاج.
